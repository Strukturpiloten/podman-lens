# Security policy

Report suspected vulnerabilities privately to
[security@strukturpiloten.de](mailto:security@strukturpiloten.de). Include reproduction steps,
affected versions, and impact without attaching real credentials, secret material, or live Podman
connection details to a public issue.

The latest published PodmanLens release is the supported pre-1.0 line. Users should upgrade to the
latest patch because older pre-1.0 releases may not receive separate fixes. Any exception will be
stated in the corresponding security advisory.

The maintainers will assess the report, coordinate a fix and disclosure where appropriate, and
credit reporters who wish to be named. Public disclosure should wait until a fix or agreed
mitigation is available.
