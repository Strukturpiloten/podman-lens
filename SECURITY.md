# Security policy

Please report suspected vulnerabilities privately to Strukturpiloten through
[security@strukturpiloten.de](mailto:security@strukturpiloten.de), with reproduction steps and the
affected PodmanLens version. Do not publish secret material, credentials, or live Podman connection
details in a public issue.

The project will acknowledge reports, assess impact, coordinate a fix where appropriate, and credit
reporters who wish to be named. The current development line has not yet made a stable security
support commitment.
